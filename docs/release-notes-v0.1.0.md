# 暗黑4 副本计数器 v0.1.0

玩《暗黑破坏神IV》时自动统计各类副本和活动完成了多少次。

## 下载

**`D4Tracker-portable.exe`** —— 单文件，免安装。双击即可运行，不需要 Node / Python / npm。

首次运行 Windows SmartScreen 可能提示"未知发布者"（未做代码签名），
点「更多信息」→「仍要运行」。

## 能计什么

| 活动 | 自动 |
|---|---|
| 梦魇地下城 / 深坑 / 炼狱魔潮 / 库拉斯特地下城 / 秘语之树 / 巢穴首领 | ✅ |
| 地狱狂潮的畸变余烬 / 灾祸之心（数值读取） | ✅ |
| 任何你想记的东西（自己加条目，+1 / −1 / 直接填数字） | 手动 |

## 使用要求

* 游戏请使用**窗口化(全屏) / 无边框窗口**，关闭 HDR，字体大小保持默认
* 独占全屏下抓不到画面 —— 这是 Windows 的限制，不是工具的问题
* 界面语言需为简体中文（模板按中文 UI 标定）

## 合规说明

**只读屏幕像素**做图像识别：不读取游戏内存、不注入 DLL、不安装键盘钩子、不模拟输入，
也不修改任何游戏文件。

暴雪 EULA 禁止的是 "modify / automate / interfere" 类软件（官方蓝贴点名过读内存的
TurboHUD4，可永久封号）。纯屏幕识别不碰游戏进程，是同类别工具（d4lf、
Diablo4Companion）长期公开采用的做法。

## 资源占用

| 状态 | CPU | 内存 |
|---|---|---|
| 游戏在前台、3fps 持续抓帧 | 20.6% 单核（16 核总算力 1.3%） | 259 MB |
| 游戏不在前台（自动跳过抓帧） | 2.3% 单核 | 213 MB |

完全离线：代码里没有任何网络调用，运行时不产生任何 TCP 连接。
计数数据存在本机 SQLite，不上传任何东西。

## 已知限制

* 巢穴首领的完成提示只停留 4~6 帧，标定样本偏少，识别把握不如其它几类
* 反例样本总量仍偏小，长时间实测的误报率还有待观察
* 安装包未做代码签名

完整说明、原理与验证数据见 [README](https://github.com/senyaqy/d4-tracker#readme)。
